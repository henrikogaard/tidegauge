# Tidegauge artwork

## Logo

- `logo.png`: the original generated activity-bar icon, 1254 × 1254 pixels, with transparency outside the rounded tile. The app embeds this image and uses it as its native application icon and in the dashboard footer.
- `tidegauge.icns`: the same artwork packaged at the standard macOS icon sizes, including 16, 32, 128, 256, and 512 pixels and their double-resolution variants. It is ready for a future app-bundle packaging workflow.

The color icon does not change the compact template symbol in the menu bar. That symbol keeps its native tint and metric layout.

## Generation prompt

The logo was created with the built-in image generator. The activity-bar version is the selected artwork.

> Use case: logo-brand. Asset type: finished macOS app icon and repository logo for Tidegauge, a system activity monitor. Create one original square icon, 1024 by 1024 pixels. Subject: a compact group of six bold vertical activity bars at varied heights, resembling a live CPU activity histogram, with a shared baseline and a balanced rising-and-falling rhythm. Each bar has smoothly rounded ends and generous separation. Make this an intentional, polished app identity, readable at 16 and 32 pixels. Center the bars with generous padding inside an inset midnight-blue rounded-square tile. Bars use luminous cyan, clear blue and icy white with restrained tonal depth; the tile has a subtle dark-blue finish. Front-facing, crisp edges, simple silhouette. Transparent canvas outside the tile. Only the finished icon. No ocean wave, gauge, text, letters, numbers, tiny details, axes, grid, logos from other products, mockups, perspective, outer shadow, surrounding scene, or watermark.
